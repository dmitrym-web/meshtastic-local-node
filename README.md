# Meshtastic Local Node

**Локальный узел Meshtastic через USB. Работает 24/7 без приложения.**

![Platform](https://img.shields.io/badge/platform-Linux-blue)
![License](https://img.shields.io/badge/license-MIT-green)

</div>

---

Нода подключается к компьютеру через USB и работает постоянно. Телефон не требуется.

Что умеет:

- принимает сообщения из эфира
- взаимодействует по протоколу MQTT на приём и передачу данных
- отправляет сообщения по команде, при необходимости можно настроить расписание рассылки
- работает без приложения
- работает с одним каналом

Всё в Docker, работает на Linux. Подходит для стационарных нод.

## Определение USB-порта ноды

По умолчанию используется `/dev/ttyACM0`. Если у тебя другое устройство или несколько USB-устройств — порт будет другим.

### Как проверить

Подключи ноду по USB и выполни:

```bash
ls /dev/ttyACM* /dev/ttyUSB*
```

Возможные варианты:

| Устройство | Типичный порт |
| :--- | :--- |
| ESP32 (Heltec, T-Beam, T114 и др.) | `/dev/ttyACM0` |
| nRF52 через USB-адаптер | `/dev/ttyUSB0` |
| Несколько нод одновременно | `/dev/ttyACM0`, `/dev/ttyACM1`, ... |

### Как узнать точнее

```bash
dmesg | grep tty
```

Или:

```bash
ls -la /dev/serial/by-id/
```

Второй вариант даёт стабильную ссылку, которая не меняется между перезагрузками.

### Как изменить порт в проекте

Порт задаётся в `.env`, переменная `SERIAL_PORT`. Внутри контейнера путь всегда `/dev/ttyACM0`.

## Права на USB-порт

Пользователь должен быть в группе `dialout`.

### Как проверить

```bash
groups
```

Если в списке нет `dialout` — добавь:

```bash
sudo usermod -aG dialout $USER
```

После этого **перезайди в сессию** (закрой и открой SSH) или выполни:

```bash
newgrp dialout
```

## Установка

### 1. Клонировать проект

```bash
git clone https://github.com/dmitrym-web/meshtastic-local-node
cd meshtastic-local-node
```

### 2. Создать `.env`

```bash
make env
```

Команда создаст `.env` из `.env.example` и запустит автоопределение ноды: найдёт подключённые USB-устройства и запишет в `.env` порт (`SERIAL_PORT`) и ID (`NODE_ID`).

Затем открой `.env` и заполни оставшиеся значения (`MQTT_BROKER`, `MQTT_USERNAME`, `MQTT_PASSWORD` и т.д.).

### 3. Запустить

```bash
make up
```

При первом запуске контейнер `meshmonitor-init` автоматически включит Virtual Node в MeshMonitor. Руками в браузере ничего настраивать не нужно.

### 4. Проверить

```bash
docker ps
```

Должны быть запущены контейнеры: `serial-bridge`, `meshmonitor`, `mqtt-proxy`, `mqtt-sub`, `mqtt-sender`.

## Использование

### Отправить сообщение сейчас

```bash
make send
```

### Отправить один раз в указанное время

```bash
make send-at
```

Спросит имя задания, дату, время и текст. Данные сохраняются в `jobs/имя.json`.

### Отправлять с интервалом

```bash
make send-every
```

Спросит имя задания, интервал (минуты/часы/дни), время первого запуска, количество раз (или бесконечно) и текст.

### Список активных заданий

```bash
make list
```

### Удалить задание

```bash
make stop
```

### Задать координаты ноды

```bash
make set-position LAT=55.7315633 LON=37.6564322 ALT=885
```

### Отправить ping

```bash
make ping
```

### Мониторинг трафика

```bash
make monitor
```

## Управление задачами с хоста

Все задания хранятся в папке `jobs/` в виде обычных JSON-файлов. Планировщик внутри контейнера (`APScheduler`) сканирует эту папку каждые 2 секунды.

- **Добавление:** Создай файл `jobs/имя.json` с нужным расписанием. Он подхватится автоматически.
- **Редактирование:** Измени время, текст или интервал в JSON-файле. Планировщик перечитает его и обновит задачу на лету.
- **Удаление:** Просто удали файл `jobs/имя.json`. Задача мгновенно снимется с выполнения.

**Никаких скрытых нюансов.** Не нужно перезапускать контейнеры или лезть в системный `cron`. Всё работает автоматически.

## Как это работает

- `serial-bridge` — держит USB-порт ноды и отдаёт его по TCP.
- `meshmonitor` — поднимает Virtual Node на порту 4404.
- `meshmonitor-init` — одноразовый контейнер для автонастройки MeshMonitor.
- `mqtt-proxy` — мостит ноду и MQTT-брокер.
- `sender` — внутри работает `scheduler.py` на базе библиотеки `APScheduler`. Он следит за папкой `jobs/`, точно выполняет задачи в часовом поясе `Europe/Moscow` и сам удаляет отработавшие задания.
- `subscriber` — слушает MQTT и печатает входящие.

## Печать и сборка на заказ

Печатаем корпуса, автономные модули и аксессуары для нод Meshtastic. Материал — PETG или ASA: устойчивы к улице, УФ и перепадам температур.

### Категории решений

**Стационарные**
- Влагозащищённые корпуса IP65 и выше.
- Крепления на мачту, DIN-рейку, стену.
- Отсек под аккумулятор, посадочные места под солнечную панель.
- Автономные сборки: нода + аккумулятор + панель + контроллер заряда.

**Переносные**
- Корпуса для Heltec V3 / V4, T-Beam, T114, RAK WisBlock, LilyGo T-Echo.
- Клипсы на ремень, карабин, MOLLE.
- Быстросъёмные крышки, отсек под сменный аккумулятор.

**Автомобильные**
- Магнитное крепление на крышу.
- Питание от прикуривателя 12 В с защитой.
- Антенны с магнитным основанием.
