# Meshtastic Local Node

**Локальный узел Meshtastic через USB. Работает 24/7 без приложения.**

Принимает сообщения из эфира, публикует в MQTT, отправляет по команде или расписанию.

## Определение USB-порта ноды

По умолчанию используется `/dev/ttyACM0`. Если у тебя другое устройство или несколько USB-устройств — порт будет другим.

### Как проверить

Подключи ноду по USB и выполни:

```bash
ls /dev/ttyACM* /dev/ttyUSB*
```

Возможные варианты:

| Устройство | Типичный порт |
| :--- | :--- |
| ESP32 (Heltec, T-Beam, T114 и др.) | `/dev/ttyACM0` |
| nRF52 через USB-адаптер | `/dev/ttyUSB0` |
| Несколько нод одновременно | `/dev/ttyACM0`, `/dev/ttyACM1`, ... |

### Как узнать точнее

```bash
dmesg | grep tty
```

Или:

```bash
ls -la /dev/serial/by-id/
```

Второй вариант даёт стабильную ссылку, которая не меняется между перезагрузками. Например:

```
usb-Silicon_Labs_CP2102_USB_to_UART_Bridge_Controller_0001-if00-port0
```

Можно использовать её вместо `/dev/ttyACM0`:

```yaml
devices:
  - /dev/serial/by-id/usb-Silicon_Labs_...-if00-port0:/dev/ttyACM0
```

### Как изменить порт в проекте

Порт задаётся в двух местах:

**`docker-compose.yml`** — три раза в сервисах `mqtt-proxy` и `sender`:

```yaml
devices:
  - /dev/ttyACM0:/dev/ttyACM0
```

**`sender/send.py`** и **`sender/set-position.py`**:

```python
PORT = "/dev/ttyACM0"
```

Замени `ttyACM0` на свой порт. Внутри контейнера путь остаётся `/dev/ttyACM0` — это фиксированное имя внутри, снаружи подставляется реальное.

## Права на USB-порт

Чтобы контейнеры и хостовые утилиты (`meshtastic`, `pipx`) могли открывать порт, пользователь должен быть в группе `dialout`.

### Как проверить

```bash
groups
```

Если в списке нет `dialout` — добавь:

```bash
sudo usermod -aG dialout $USER
```

После этого **перезайди в сессию** (закрой и открой SSH) или выполни:

```bash
newgrp dialout
```

Проверь ещё раз:

```bash
groups
```

Должно быть `dialout`.

### Как проверить доступ к порту

```bash
ls -la /dev/ttyACM0
```

Должно быть что-то вроде:

```
crw-rw---- 1 root dialout 166, 0 Oct 14 12:00 /dev/ttyACM0
```

Владелец — `root`, группа — `dialout`. Если ты в группе `dialout`, у тебя есть доступ на чтение и запись.

### Быстрая проверка

```bash
sudo chmod 666 /dev/ttyACM0
```

Это даст доступ всем. **Не используй как постоянное решение** — только для проверки, что проблема в правах. Если после этого всё заработало — значит, ты не в группе `dialout`, вернись к шагу с `usermod`.

## Установка

### 1. Клонировать проект

```bash
git clone https://github.com/dmitrym-web/meshtastic-local-node
cd meshtastic-local-node
```

### 2. Создать `.env`

```bash
make env
nano .env
```

Заполнить значения:

| Переменная | Пример | Назначение |
| :--- | :--- | :--- |
| `MQTT_BROKER` | `meshtastic.meshradio.online` | Адрес брокера |
| `MQTT_PORT` | `1883` | Порт брокера |
| `MQTT_USERNAME` | `user` | Логин |
| `MQTT_PASSWORD` | `pass` | Пароль |
| `MQTT_ROOT_TOPIC` | `msh/nvrsk` | Корневой топик |
| `SCHEDULED_TEXT` | `Привет по расписанию!` | Текст по умолчанию |
| `CHANNEL_INDEX` | `0` | Номер канала |

### 3. Запустить

```bash
make up
```

### 4. Проверить

```bash
docker ps
```

Должны быть три контейнера: `mqtt-proxy`, `mqtt-sub`, `mqtt-sender`.

Логи прокси:

```bash
make logs
```

Ожидаемые строки:

```
✅ Node config fully loaded. Proxy active.
✅ MQTT Connected with result code: Success
```

## Использование

### Отправить сообщение сейчас

```bash
make send
```

Спросит текст, отправит.

### Отправить один раз в указанное время

```bash
make send-at
```

Спросит время (`today 14:30` или `tomorrow 09:00`) и текст.

### Отправлять с интервалом

```bash
make send-every
```

Спросит имя задания, интервал (`30m`, `2h`, `1d`) и текст.

### Список активных заданий

```bash
make list
```

### Удалить задание

```bash
make stop
```

### Задать координаты ноды

```bash
make set-position LAT=55.7315633 LON=37.6564322 ALT=885
```

### Отправить ping

```bash
make ping
```

## Как это работает

### Отправка сообщения

1. `send.py` внутри контейнера `mqtt-sender` останавливает `mqtt-proxy` — освобождает USB-порт.
2. Открывает ноду через Python-библиотеку `meshtastic`.
3. Отправляет текст в канал.
4. Закрывает ноду.
5. Запускает `mqtt-proxy` обратно.

### Расписание

1. Скрипт сохраняет текст в файл `/tmp/scheduled-*.txt`.
2. Добавляет задание в хостовый crontab с тегом `meshtastic-local:<имя>`.
3. В назначенное время cron запускает скрипт-обёртку.
4. Скрипт читает текст из файла и вызывает `docker exec` в `mqtt-sender`.
5. Разовое задание удаляет себя из crontab после отправки.

Задания помечены тегом — `make stop` и `make list` работают только с ними, личные записи в crontab не трогаются.

## Ограничения

- **Только Linux.** На Windows не работает — хостовый cron, `/dev/ttyACM0`, `docker.sock`.
- **Одна нода — один процесс.** USB-порт монопольный. Пока `mqtt-proxy` работает, `send.py` останавливает его на время отправки.
- **Нет локального веб-интерфейса.** Входящие сообщения видны в `make sub-log` (MQTT-топики), в MeshMonitor и Telegram.

## Печать и сборка на заказ

Печатаем корпуса, автономные модули и аксессуары для нод Meshtastic. Материал — PETG или ASA: устойчивы к улице, УФ и перепадам температур. Возможна сборка «под ключ» с электроникой.

### Категории решений

**Стационарные**
Для установки на мачту, столб, стену, крышу. Расчёт на долгую работу без обслуживания.
- Влагозащищённые корпуса IP65 и выше.
- Крепления на мачту, DIN-рейку, стену.
- Отсек под аккумулятор, посадочные места под солнечную панель.
- Вынос антенны на кронштейне.
- Автономные сборки: нода + аккумулятор + панель + контроллер заряда.
- Датчики температуры, влажности, давления.
- Корпуса и рамы для солнечных панелей 5–50 Вт, поворотные механизмы по азимуту и наклону.

**Переносные**
Для походов, выездов, работы в поле. Лёгкие, компактные, с быстрым доступом к питанию.
- Корпуса для Heltec V3 / V4, T-Beam, T114, RAK WisBlock, LilyGo T-Echo.
- Клипсы на ремень, карабин, MOLLE.
- Быстросъёмные крышки, отсек под сменный аккумулятор.
- Внешний разъём для антенны.
- Упрочнённые версии для тяжёлых условий.

**Автомобильные**
Для установки на машину с питанием от бортовой сети.
- Магнитное крепление на крышу.
- Питание от прикуривателя 12 В с защитой.
- Антенны с магнитным основанием.
- Быстросъёмные крепления — снимаются на стоянке за секунды.

**Индивидуальные**
Под нестандартную сборку: специфические платы, необычное питание, свои размеры, крепления, компоновка.

### Комплектующие и аксессуары

- Прокладки, винты, влагозащита.
- Контроллеры заряда MPPT / PWM, кабели, разъёмы.
- Антенны и кронштейны.
- Защитные кожухи для панелей: от града, ветра, обрастания.
- Цвета: чёрный, белый, серый, оранжевый. Другие — по запросу.
